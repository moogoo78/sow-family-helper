# 荒野親子團通訊錄

一個給荒野親子團自己用的通訊錄：手機上打開、輸入一組共用密碼，就能查團員、
分團名單、家庭與歷年職務。整包只有 Python 標準函式庫加一個 SQLite 檔，
沒有任何第三方套件，`python3 server.py` 就跑得起來。

不是通用型的名冊系統——資料結構與各種判斷規則都是照這個團的實際資料長出來的
（見 `groups.private.md`）。

## 功能

- **分團**：五個團的卡片 → 工作人員／小孩兩張卡 → 名單。工作人員依
  團長 → 副團長 → 導引員 → 攝影官 排序。
- **個人頁**：家庭成員、入團年、歷年職務（列表＋甘特圖）、培訓紀錄。
- **培訓紀錄**：每一門課點得進去看誰上過，另有「上過蟻／蜂／鹿／育／鷹基」
  的彙整；個人頁的每一列培訓也是連結。名單**包含已經離團的人**（另一個顏色、
  排在後面、標第幾年離團）——上過基訓的人有一半以上已經離團，只列現役的話
  名單會少一半。其他地方（搜尋、分團、新家庭）仍然只有現役團員。
- **第 N 年新家庭**：本年度新加入的家庭。
- **歷年團會長**：一年一段，列出當年的複式團長、各團團長與育成會長。
  早年的團長有些已經離團，名字照樣列出來，只是點不進去。
- **搜尋**：自然名、姓名、家庭名都比對得到。
- 手機優先、支援深色模式，可以加到主畫面當 PWA。

姓名只出現在個人詳細頁，名單列一律只顯示自然名。

## 跑起來

```bash
python3 scripts/set_password.py     # 設定共用密碼（寫進 north7.sqlite）
python3 server.py                   # http://localhost:8000
```

需要 Python 3.8 以上，沒有其他相依套件。`HOST`／`PORT` 可以用環境變數換掉。

用 Docker 的話：

```bash
make up          # 建置＋啟動，綁在 127.0.0.1:8010
make logs        # 看 log
make down        # 停掉
```

正式部署（含 Traefik + TLS）看 [DEPLOY.md](DEPLOY.md)。

## 資料

`north7.sqlite` **不在這個 repo 裡**，也不會被打包進 image——它同時放著團員個資
與登入密碼的雜湊，執行時才掛進去。

兩份筆記 `schema.private.md`（資料表、可選的聯絡欄位、資料現況的已知問題）
與 `groups.private.md`（團別代碼、工作人員／小孩怎麼分、職務命名與排序、年度、
以及**同自然名不同人**的處理方式）**也不在這個 repo 裡**——裡面舉的例子都是
真的自然名與姓名，跟 `north7.sqlite` 一起放在 host 上（`.gitignore` 擋掉
`*.private.md`）。匯入資料前值得先讀後面那一份。

`scripts/` 裡進到 repo 的只有兩支，都沒有個資：

| script | 做什麼 |
| ------ | ------ |
| `set_password.py` | 設定共用密碼，順便換掉 session 簽章金鑰 |
| `normalize_training_names.py` | 統一課程名稱寫法（`蜂十七基` → `北蜂17基`） |

其餘的名冊匯入與資料修復 script（`import_n7_10.py`、`fix_nickname_merges.py`、
`merge_duplicate_people.py`、`merge_duplicate_families.py`、
`restore_none_role_rows.py`、`split_shared_nicknames.py`）**跟那兩份筆記一樣
留在 host 上**——要拆同自然名的人、要合併重複資料，就得把姓名、自然名、生日
一筆一筆寫在程式裡，等於把名冊抄進原始碼。它們預設 dry run，加 `--apply`
才會寫入，而且都可以重複執行。

會有那幾支的原因是：**自然名會重複**，早期匯入用自然名比對，於是有人的資料
被掛到同名的另一個人身上。要自己寫匯入程式的話，先比姓名，別只比自然名。
